# Nova

Sistema de gestión empresarial para una juguetería familiar. Nova centraliza catálogo, inventario por ubicación, clientes, ventas, cobros, compras, anticipos a proveedores, devoluciones, gastos e indicadores del negocio.

El producto se construye como un monorepo con frontend Next.js, backend NestJS y documentación versionada junto al código.
