## Convenciones

- Estado permitido: `Confirmada`, `Borrador` o `Fuera del MVP`.
- Una historia expresa actor, acción y resultado de negocio.
- Cada escenario contiene un solo evento y un solo resultado verificable.
- Las decisiones técnicas se documentan como tareas o ADR, no como historias.
