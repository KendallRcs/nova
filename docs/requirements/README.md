## Cómo modificar el alcance

1. Identifica la historia afectada.
2. Modifica o añade un escenario con un solo `Cuando` y un solo `Entonces`.
3. Actualiza las reglas transversales si la decisión afecta más de un módulo.
4. Registra el cambio en `CHANGELOG.md`.
5. Revisa el modelo de dominio y los ADR relacionados.
