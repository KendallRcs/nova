# Lenguaje ubicuo

**Estado:** borrador inicial para validar durante la Fase 3.

| Término | Significado inicial | Evitar confundir con |
| --- | --- | --- |
| Stock físico | Unidades que se encuentran físicamente en una ubicación | Stock disponible |
| Stock reservado | Unidades físicas comprometidas con una venta | Unidades entregadas |
| Stock disponible | Unidades físicas que todavía pueden ofrecerse | Stock físico total |
| Venta | Acuerdo comercial con uno o más productos y un total acordado | Pago o entrega |
| Línea de venta | Producto, cantidad, precio y cumplimiento dentro de una venta | Producto del catálogo |
| Reserva | Compromiso que bloquea disponibilidad sin retirar físicamente la unidad | Venta a crédito |
| Entrega | Salida física de unidades hacia el cliente | Pago |
| Pago | Entrada de dinero vinculada con una venta | Total acordado |
| Saldo | Importe vigente que todavía se espera cobrar | Monto condonado |
| Cierre incompleto | Finalización autorizada sin cobrar todo el saldo | Venta pagada |
| Compra | Adquisición confirmada de mercancía que ingresa al inventario | Gasto operativo |
| Anticipo a proveedor | Dinero entregado antes de concretar una o más compras | Gasto operativo |
| Egreso | Salida real de dinero | Gasto o costo de venta |
| Gasto operativo | Consumo relacionado con operar el negocio | Compra de inventario |
| Baja de inventario | Retiro trazable de unidades no vendibles | Eliminación de un producto |
| Ajuste de inventario | Corrección de una diferencia encontrada | Baja con causa conocida |
